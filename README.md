# Putra Irfan — Personal Portfolio

Personal portfolio website for **Putra Irfan** (*Industrial Mathematics & Data Analytics*), built with React, TypeScript, Vite, and Tailwind CSS.

## Highlights
- **Interactive Arctic Hero**: 3-scene auto-circulating winter carousel, procedural canvas waving flag, chimney smoke, snowfall, and interactive igloo hover warmth & embers.
- **Selected Projects**: SQLQuest, PyQuest Academy, District School Health & BMI SQL Analysis, and Automated School Monitoring & Result System.
- **Technical Skills & Tools**: Data & Analytics, Mathematical & Scientific Modeling, and Web & Workflow Automation.
- **Editorial Resume & Print-Ready A4 CV Modal**: Two-column timeline with PDF download and clean `@media print` A4 export.
- **About & Contact**: UTM / Johor editorial bio and direct links to Email, LinkedIn, and GitHub.

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

> Add your resume PDF at `public/Putra_Irfan_Resume.pdf` before deploying so the **Download Resume (PDF)** button serves it directly.
